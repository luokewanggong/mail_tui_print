# Linux系统自动收到邮件下载并连接打印机打印
# The Linux system automatically receives emails, downloads them, and connects to the printer to print.
  mail_tui.sh
  
  使用办法，
  
  1.将mail_tui.sh传到服务器
  
  2.使用 chmod +x mail_tui.sh  #授予权限
  
  3.  ./mail_tui.sh           #执行程序

  Usage instructions: 
  1. Transfer mail_tui.sh to the server.
     
  2.  Use `chmod +x mail_tui.sh` to grant permissions.
     
  3. Execute the program by running `.\/mail_tui.sh`.
  
# window系统系统自动收到邮件下载并连接打印机打印
# #Windows system automatically receives emails, downloads them, and connects to a printer for printing.
  MailAutoPrintWinExE.exe
  
  使用办法，
  
  下载双击执行
  
  仅仅支持QQ邮箱

  Usage instructions: Download,
  
  double-click to execute. 
  
  Only supports QQ email accounts.
